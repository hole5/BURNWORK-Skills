# 声音计划（可选）

在视频提示词之后、生产之前，可为单集写一份可读的声音意图。**不**成为第六份强制创作真相；
没有本文件时，声音仍写在剧本声源、分镜「声音」字段与 `视频提示词.md` 里。

## 何时写

- 导演 pass 用户点名「含声音计划」；
- 对白/底声/静默/音乐意图跨多镜冲突，需要一页对齐；
- 进入剪辑前要先锁声轨策略。

落盘（可选）：`剧集/<EP>/声音计划.md`

## 模板

```markdown
# EP### 声音计划

- 总态度：对白主导 / 底声戏剧 / 静默压迫 / …
- 音乐：无主题曲 | 时间线配乐意图见 视频提示词.md | 剪辑后再定
- 未决：…

## 分镜声轨

| 镜 | 对白/VO/OS | 动作声 | 环境底 | 静默 | 音乐入点 |
|---|---|---|---|---|---|
| SHOT-… | … | … | … | 有/无 | … |

## 禁区

- （例）对白镜禁止抢戏 BGM）
- （例）无对白镜必须写明底声或静默，见 VID-22/23）
```

## 规则

1. 台词原文仍以 `剧本.md` 为准；本表不改词。
2. 与分镜「声音」字段冲突时，以更新的那一份为准，并在末报说明。
3. 画音同轨模型：口型与发声边界仍由视频提示词承担；本表管跨镜策略。
4. 剪辑阶段可把本表意图落实到剪辑单的声轨说明，但不自动重生成视频。
