# 导演阐述下沉检查（分镜前置）

在写或大改 `剧集/<EP>/分镜.md` **之前**执行。目的：把 `项目开发/director-brief.md`（若存在）
里的镜头语法、禁区与回报节奏，变成可执行的分镜约束，而不是停在项目开发文件夹里的散文。

## 1. 读取

按顺序尝试（找到就停）：

1. `项目开发/director-brief.md`
2. 创作者点名的其他导演阐述路径

都没有：在本集分镜末报写一行「未锁定导演阐述」；**不阻断**分镜。不要伪造阐述。

## 2. 提取（只抽可执行项）

从阐述中列出短表（每条一行，写进分镜工作备注或末报，不另造第六份创作真相）：

| 字段 | 抽什么 |
|---|---|
| 镜头语法 | 景别偏好、固定/手持、轴线态度、是否允许多机 |
| 禁区 | 明确禁止的手法、擦边、字幕区、不得提前剧透的信息 |
| 回报节奏 | 首钩、中段兑现、集尾停点（相对秒或节拍） |
| 空间权力 | 谁占画面优势、谁被压迫 |
| 声音态度 | 对白主导 / 底声 / 静默是否被强调 |

阐述含糊到抽不出可执行项时，记「阐述过虚，按剧本与节奏档案默认」并继续。

## 3. 下沉到分镜

- 禁区：任何拟用手法落在禁区 → 改方案或标未决问创作者。
- 回报节奏：与已接受 `rhythm_profile` 冲突时，以创作者最新接受的档案为准，并在末报说明差异。
- 镜头语法：作为默认，可被单场 Coverage Audition 的更好方案覆盖，覆盖时写一句理由。

## 4. Coverage

导演 pass 或整集正式分镜时：**每一场**做 Coverage Audition（见 `coverage-audition.md`）。
普通「只补一镜」请求不强制全场试听。
