# 风格透镜（可选）

用户点名一套透镜时，分镜/视频提示词在**不违反阐述禁区与节奏档案**的前提下，用该套默认覆盖景别、运镜、光比与切点偏好。一次只用一套；未点名则不加载。

| ID | 文件 | 适用 |
|---|---|---|
| `lens-tense-realism` | [lens-tense-realism.md](lens-tense-realism.md) | 写实紧张、职场/犯罪压力 |
| `lens-comedy-snap` | [lens-comedy-snap.md](lens-comedy-snap.md) | 喜剧轻切、反应镜 |
| `lens-romance-soft` | [lens-romance-soft.md](lens-romance-soft.md) | 浪漫柔光、眼神戏 |
| `lens-action-clear` | [lens-action-clear.md](lens-action-clear.md) | 动作清晰可读 |
| `lens-suspense-press` | [lens-suspense-press.md](lens-suspense-press.md) | 悬疑压迫、信息暂缓 |
| `lens-comic-flat` | [lens-comic-flat.md](lens-comic-flat.md) | 漫剧/平面图形感 |

加载后在分镜末报写：`风格透镜：<ID>`。
