# 镜头难度与重试预算

分镜可为每镜声明难度，供生产排队与 QC 三振使用。难度是创作标注，不是供应商 SLA。

## 分镜字段

在 `## SHOT-…` 下增加一行（可选，缺省按 `M`）：

```text
难度：S | M | L | XL
```

| 级 | 含义 | 生产含义 |
|---|---|---|
| S | 单人/固定/短对白或无对白 | 可优先批量 |
| M | 常规对白或简单动作 | 默认 |
| L | 多人调度、明显运镜、持物交接 | 单条确认；失败先 QC 便宜修复 |
| XL | 群戏、特效峰值、复杂口型+动作 | 禁止与 L/XL 无确认连跑；三振后必停 |

## 重试预算

| 级 | 同码自动重试上限 | 说明 |
|---|---|---|
| S/M | 2 | 第 3 次同码失败 → 停 |
| L | 1 | 第 2 次同码失败 → 停 |
| XL | 0 | 首次内容失败即停，只允许改 job 后经确认再投 |

技术失败（超时/限流）不占内容三振名额，但仍须新确认。

账本（可选）写在 `剧集/<EP>/制作成果/qc-retries.jsonl`：

```json
{"shot_id":"SHOT-EP001-003","code":"QC-ID","attempt":1,"action":"swap_ref","at":"ISO-8601"}
```

## 与导演 pass

整集分镜结束时，末报给出 S/M/L/XL 计数；生产页批量时按 L/XL 拆出需单独确认的条目。
