# 灯光圣经（跨镜光锁）

在 `lighting-craft.md`（单镜怎么写光）之上，锁定**一场戏内**不可漂的光事实。
可选落盘：`剧集/<EP>/灯光圣经.md` 或写在 `视觉设定.md` 地点条目的「光线状态」下。

## 一场一锁

连续场景（同一时空、无转场跳切到另一时）声明：

| 锁 | 写什么 |
|---|---|
| 主光方向 | 画面左/右/顶/逆；相对人物哪侧 |
| 色温态度 | 冷/中性/暖；是否允许矫色漂移 |
| 时段 | 日/黄昏/夜/室内人工 |
| 可读底线 | 哪张脸或证据必须始终可读 |
| 禁区 | 禁止无动机换主光方向、禁止突然轮廓光等 |

## 分镜如何引用

- 开场首镜写全锁；后续镜写「光锁：同 SC00x」或只写相对变化（「停电后主光灭，只留窗外蓝光」）。
- 变化必须来自剧本或已接受设定（开关灯、日出），不能为「好看」偷换方向。

## 审查

相邻可比较镜头若主光左右对调且无剧情动机 → 记 `QC-STY` / 视觉审查表连续性项。
