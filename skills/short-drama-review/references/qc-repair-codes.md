# QC 修复码（v0）

生产或审查发现失败时，先定机制再选**最便宜**修复，不要默认整镜重滚。
本表不替代各审查表的 blocker 结论；它给 produce / review 一个共享的修复阶梯。

## 用法

1. 归入下表一个码（可多码）。
2. 按「修复阶梯」从上到下试；上一级能解决就停。
3. 在审查或生产备注写：`QC-<码> · 机制 · 本步修复 · 是否仍需重生成`。

## 码表

| 码 | 机制 | 常见表现 | 修复阶梯（便宜 → 贵） |
|---|---|---|---|
| QC-ID | 身份漂移 | 换脸、换装、年龄跳 | 核对连续性锁 → 换 REF → 重出该关键帧 → 重视频 |
| QC-AXIS | 轴线/视线 | 左右跳切、眼神错位 | 改分镜朝向字段 → 重关键帧 → 重视频 |
| QC-PROP | 持物/状态 | 道具消失、杯液反涨 | 改起止态 → 重关键帧 → 重视频 |
| QC-MOT | 动作越界 | 镜内多动作、终点提前出现 | 收紧唯一动作 → 重视频提示词 → 重视频 |
| QC-DUR | 时长不适配 | 被模型截断/拖镜 | 按 native_duration 切镜 → 改提示词时长 → 重跑 |
| QC-LIP | 口型/对白 | 错词、哑口、错人声 | 核对剧本原句 → TTS/口型参数 → 重视频（画音同轨） |
| QC-AUD | 声音层 | 底噪、无静默说明、串乐 | 补 VID 声音字段 → 剪辑单改带 → 重混音 |
| QC-SUB | 字幕/画面字 | 错字、挡脸、与剧本不符 | 改剪辑单字幕 → 重烧录；不改故事则不动剧本 |
| QC-COV | 原文未承载 | 对白/动作无镜头 | 回 storyboard 补镜 → 再提示词 → 再生 |
| QC-STY | 风格漂移 | 光色/时代跳 | 查阐述禁区与设定锁 → 重图侧 → 重视频 |
| QC-GEN | 不可生成 | 厂商拒绘、空黑帧 | 降难度/改可生成描述 → 换适配器 → 拆镜 |
| QC-EDIT | 剪辑接缝 | 跳帧、响度跳、镜序错 | 只改剪辑单入出点 → 重渲染成片 |

## 三振

同一 `SHOT-…` 同一码连续失败 3 次：停止自动重试，汇总给创作者（换方案 / 降难度 / 人工素材）。

## 与现有规则

- 审查表仍用 `SHT-*` / `VID-*` / `STY-*` 等写证据。
- 本码用于**修复动作**选型；可在审查「修订结果」行附 `QC-…`。
