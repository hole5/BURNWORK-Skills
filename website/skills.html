技能库

一套装进编程 Agent 的短剧技能：从点子或原著走到剧本、设定、分镜、提示词与成片。工作室负责浏览与确认生产，技能负责按阶段写文档。

覆盖什么

  • 原著分析、故事开发、单集写作
  • 视觉资产、图片 / 视频提示词、分镜
  • 确认后的生产、剪辑与审查

和工作室的关系

五份 Markdown 仍是创作事实。技能可读写同一项目；BURNWORK Studio 提供本机界面、项目目录与 ComfyUI 确认投产。
