工作室说明

BURNWORK Studio 是 Windows 上的本机短剧工作台：浏览五份创作文档、看分镜与角色，在右侧与 AI 对话，确认后再交给本机 ComfyUI。

怎么打开

  • Windows：运行 scripts\open-studio.bat
  • 需要 .NET 8；首次会编译桌面程序
  • 非 Windows：可用浏览器对照页启动同一套后端

默认目录

工作室根默认在「文档 / 燃烧工作室」，下分 projects、skills、assets。路径写在本机配置里，可在设置中更改。

生产页只有在设置里启动出图 / 出视频后端后，才会把「预览并生成」交给该后端。
