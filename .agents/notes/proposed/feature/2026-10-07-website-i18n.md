# Agent Note: 官网中英双语切换

Status: proposed

## Problem

官网只有中文文案，参照站 Reelbench 有「中文 / EN」切换；创作者要求主页加入双语切换。

## Proposal

共用 `website/i18n.js`：顶栏 `中文 | EN` 切换，选择写入 `localStorage`，用 `data-i18n` / `data-i18n-html` 替换可见文案。首页全文双语；子页至少顶栏、页脚与正文简介同步，避免切到英文后点进子页又全是中文。

## Alternatives considered

- **单独 index.en.html** — 最强理由：无 JS、SEO 清晰。不用：维护两套 DOM，切换体验不如单页切换。
- **只做首页、子页不译** — 最强理由：改动面小。不用：导航进子页语言会断。

## Consequences

- **收益**：与参照站一致的语言切换体验。
- **代价**：之后改文案要同时维护中英字典。
