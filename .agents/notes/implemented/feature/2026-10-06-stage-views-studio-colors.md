# 主栏印张改回暗金配色

## Problem

角色/剧本/分镜主栏用了参考 HTML 的冷灰纸面，和墨场工作台夜色底、金描边、奶油字不一致；纸面上的深灰正文对比也不够。

## Decision

主栏结构不变，色彩并入现有工作室 token：底 `Bg`/`Surface`，线 `Line`，正文 `Ink`/`SoftInk`，强调与选中用 `Gold`/`GoldWash`。质量门失败用 `Warn`，不再用铁锈红。设定图位改为暗底空框。节奏条改成金灰阶，适配暗底。

## Alternatives considered

- **只把纸面字加深、继续浅底**：最强理由是保留报告阅读感。不用：创作者已判定和程序风格冲突。
- **整窗改浅色**：最强理由是和 HTML 报告同构。不用：外壳已经是暗金工作台。

## Consequences

版式仍是花名册/对白三列/镜卡；主栏不再出现第二套浅色皮肤。与 [暗壳 + 浅色印张](2026-10-06-wpf-paper-stage-views.md) 的配色决定相反，结构决定仍有效。
