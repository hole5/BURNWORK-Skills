# Agent Note: 聊天拖放与按项目对话落盘

Status: implemented

## Problem

聊天不能拖入文件；对话只在内存，重开项目丢失。删除项目时对话也不在项目目录里。

## Decision

AI 面板与输入框接受拖放 txt/md/图片，走现有附件逻辑。对话写入该项目 `项目开发/对话.jsonl`：打开加载、每轮与回首页/关窗口保存。删除项目时连文件夹一起进回收站，对话一并去掉；若正打开该项目则先清空内存、不回写。

## Alternatives considered

- **对话写进 ~/.mochang/chat.json** — 最强理由：和 API 配置一处。不用：会把多项目记录混在全局，删项目无法同步。
- **只在关闭窗口时保存** — 最强理由：写盘少。不用：崩溃或强杀会丢本轮。

## Consequences

- **收益**：重开项目能接上聊天；删项目记录一起没；拖文件与曲别针一致。
- **代价**：`项目开发/对话.jsonl` 可能变大；原文摘录会进对话文件。
