# Agent Note: 首页与聊天可附加原著和参考图

Status: implemented

## Problem

首页「+ 参考内容」只提示把图放到项目里，并不能选文件。工作台聊天也没有附件入口，改编小说或按图写设定时材料进不了对话。

## Decision

「+ 参考内容」和聊天曲别针都弹出「小说原文 / 参考图」。原文进 `项目开发/原著/`（对话带前 8000 字），图片进 `制作成果/参考/` 并显示微缩图。创建项目时一并拷入；聊天发送把路径和摘录交给技能循环，气泡只显示文件名。

## Alternatives considered

- **把图片 base64 塞进多模态请求** — 最强理由：模型能直接看图。不用：本地 completions 多数无视觉，且体积大。
- **只允许工作台附件** — 最强理由：创建前没有项目目录。不用：新建改编项目必须能先挂原著。

## Consequences

- **收益**：改编和设定有明确材料入口，附件落在项目约定目录。
- **代价**：超长原文会截断；图片只传路径，不会在模型里成像。
