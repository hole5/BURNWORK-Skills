# Agent Note: 燃烧工作室官网主页

Status: implemented

## Problem

产品已有桌面壳与品牌（燃烧工作室 / BURNWORK），仓库没有对外落地页。需要参照 [Reelbench](https://reelbench.79px.com/) 的结构（英雄区、能力三件套、工作流步骤、离线承诺、页脚），但文案与转化要符合本机短剧工作室与 MIT 开源事实，不能照搬付费套餐。

## Decision

在 `website/` 放单页静态站：炭黑底 + 余烬金（对齐工作室主题色），英雄区品牌优先，下方三件套（技能创作中枢 / ComfyUI / 五文档资产）、四步工作流、本机数据承诺与启动 CTA。视觉用 `brand-mark` 与首页氛围图，界面示意用 CSS 构图，不引入虚构定价。

## Alternatives considered

- **直接复刻 Reelbench 含 $199/$399** — 最强理由：结构成熟、转化清晰。不用：本产品非该商业模型，会误导。
- **只改 README 外链文案** — 最强理由：零前端。不用：创作者要的是可打开的程序官网主页。

## Consequences

- **收益**：有可本地打开的品牌落地页，结构与竞品参照对齐。
- **代价**：需维护静态页文案；日后真截图应替换 CSS 示意。
