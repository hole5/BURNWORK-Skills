# Agent Note: 创作台改成深色工作台外壳

Status: implemented

## Problem

创作台按阶段分视图之后，打开仍是浅色纸面加一条横向阶段栏。对照另一套短剧技能的工作台（左侧阶段、分集列表、阶段总表、底栏），创作者第一眼看到的仍是文档页，而不是「这一阶段各集进行到哪」。

## Decision

`skills/short-drama/assets/dashboard/` 的外壳改成工作台：宽屏在本集页面用左侧阶段栏、分集列表和底栏；全剧页增加分镜覆盖表，列出已有分镜的镜数、总时长、均镜长，以及已有剧本但还没有分镜的集。颜色放在 `tokens.css` 的 `:root[data-skin="bench"]`，创作台默认带上这个皮肤；创作者切到浅色时去掉皮肤，回到原来的纸面。`styles.css` 仍只引用 `--zs-*`。

路由、五份 Markdown 真相、服务端解析和「复制给助手」不变。阶段栏仍是 `#stagebar` 里的概况、剧本、设定、分镜、提示词、成片、审查。窄于 1100px 时分集列表收起，阶段栏回到顶部横条，避免窄屏横向溢出。

## Alternatives considered

- **把真相改成 JSON，再渲染一份独立 HTML 报告** — 最强理由：总表可以直接按字段画，不必从 Markdown 现解析。不用：0.6 已把创作者真相定为五份 Markdown，再加一份报告会变成第二套要维护的正文。
- **在页面上放「一键生成」并直接投产** — 最强理由：和参照工作台的按钮一致。不用：创作台不发起生产；生成仍是把一句话复制回对话，确认后才执行。

## Consequences

- **收益**：宽屏能同时看到当前阶段、其他集的进度和这一集的正文；分镜覆盖能看出哪几集还没写分镜。
- **代价**：`tokens.css` 多了一套可选皮肤。别的创作台不写 `data-skin="bench"` 时外观不变；若整份文件被同步过去，也要一起带上这段。
- **已知上限**：分集列表只在本集页面、且视口至少 1100px 时出现。全剧页的分镜覆盖只用系列接口里的镜数和时长，不在这一页展开每一镜。
