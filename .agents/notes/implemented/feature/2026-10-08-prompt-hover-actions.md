# Agent Note: 提示词悬停复制与喂给小烧

Status: implemented

## Problem

提示词页每条只是只读文本框，要复制或交给右侧 AI 聊天需手选全文。创作者要求悬停显示「复制提示词」与「喂给小烧」。

## Decision

`BuildPrompts` 每条提示词包一层可悬停容器：鼠标进入显示「复制提示词」「喂给小烧」；复制走剪贴板；「喂给小烧」把正文写入 `ChatInput`（不自动发送），便于改完再发。悬停时描边改为金色。

## Alternatives considered

- **喂给小烧直接发送** — 最强理由：少一步。不用：创作者写的是「提交到聊天框」，应可先改再发。
- **只在文本框右键菜单** — 最强理由：不挡正文。不用：不够一眼可发现。

## Consequences

- **收益**：提示词可一键复制或交给助手。
- **代价**：悬停层略挡右上角正文；长提示词仍靠文本框滚动阅读。
