# Agent Note: 最近打开去重按打开时间排序

Status: implemented

## Problem

侧栏「最近打开」把同一项目列出多次（迁移后 id/路径不同），第二行又把目录名当成说明，看起来像项目名重复。底部「+ 小说项目」在固定 32px 高度上叠了更大 Padding，文字偏下。

## Decision

`recent.json` 按项目文件夹名（没有路径时用 id）合并，保留最新 `OpenedAt` 并按该时间倒序。列表第二行只写「短剧项目 · 时间」，不再写完整目录。底部按钮改为 44px 高、垂直 Padding 为 0，文字居中。

## Alternatives considered

- **只按 id 去重** — 最强理由：Touch 已按 id 删旧项。不用：工作区迁移后同一文件夹会换 hash id，仍会重复。
- **按标题去重** — 最强理由：截图里标题完全一样。不用：两个合法项目可能同名。

## Consequences

- **收益**：同一项目只占一行，最新打开在最上；底部按钮文字不再挤偏。
- **代价**：不同目录下同名文件夹会被当成同一项；读 `recent.json` 时会写回合并结果。
